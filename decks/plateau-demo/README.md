# PLATEAU 2026 demo

This is a preserved snapshot of the editable PLATEAU talk as of 2026-10-15:
20 slides, with all speaker notes and the current canvas layout.

Open `/canvas.html?deck=plateau-demo`, or choose **PLATEAU 2026 demo** in the
Deck picker. Edits are saved only in this browser, including under
`npm run dev`; they never write back to this example's source file. Download
source exports your edited copy as `plateau-demo.sw`.

The UIST 2026 working talk is at `decks/uist-2026/deck.sw` and
`/canvas.html?deck=uist-2026`, with continuous development-server write-back.
The demo shares its component registry, fonts, images, and videos. See the
[working talk README](../uist-2026/README.md) for local media setup and
presentation controls; the headshot and videos are not included in Git.
